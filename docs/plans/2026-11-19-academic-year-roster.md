# 四查汇总前置功能：学年名单与固定年级授权

## 学年配置

超级管理员在「学期与周次 → 学年 → 配置学年名单」打开名单抽屉，第一步在左侧选定年级，在纵向树中勾选该年级开设的专业，点击专业左侧箭头展开班级；没有班级的专业作为叶节点展示。专业行右侧对齐显示本年级该专业的启用班级总数，独立于勾选状态。第二步核对导出层级，选择一个同级列表拖动或用箭头调序。返回上一步保留草稿，最后统一保存。「查看顺序」按保存顺序展示年级与专业，支持逐个展开或收起年级和专业以查看班级；「配置学年名单」回显原名单，点击「下一步」即可调序。同一年级内的专业顺序独立保存，每个专业下的班级也独立排序。首次选择专业时自动带入启用班级，按阿拉伯数字或中文班号自然升序排列。可逐行上移、下移，或恢复班号升序。既有名单保留上次保存的顺序。可从较早的已配置学年复制，保存前仍可调整。

沿用学年创建和更新接口及学年版本号。可选字段 `roster.majorIds` 保留学年专业集合以兼容已有客户端，`roster.grades` 给出年级顺序。各年级的 `majors` 按展示顺序列出适用专业，各专业的 `classIds` 表达班级顺序。服务器检查唯一性、启用状态和班级实际归属。编辑使用乐观锁；写入与审计同一事务提交。省略名单字段的旧客户端保留已保存的名单。已有检查记录引用的班级须在名单内。

## 报表与检查

新学年的手工检查与导入仍需有效授权，配置名单进一步限定可选班级。未配置名单的历史学年沿用旧通报覆盖。已配置学年生成通报时固化班级序列和年级专业组合，Word/Excel 从选定版本读取。旧版本缺少配置标记时沿用旧渲染顺序。班级指标保留已配置的空班，年级应到人数包括已配置专业的在籍未分班学生。名单与班级基础归属冲突时需修订配置后重新生成。

四查汇总表后续可复用同一有序名单。处分累计和汇总表的统计口径、审批流程及正式模板仍按各自需求验收。

## 人工处理旧阶段授权

1. 在「用户与角色 → 旧阶段授权清单」按部门、岗位、动作和检查类型核对待处理项。清单包含仍启用且未到期的个人规则、部门模板和仍未到期的已授予快照，包括将来才开始的授权。
2. 管理员先调整岗位模板，再进入账号权限详情，逐项确定具体年级或终止授权。选择具体年级时核对原专业、班级、部门和有效期。保存模板不会追溯更新已授予权限。
3. 原始快照保留作追溯，个人覆盖和禁用规则有自己的有效期。取消覆盖或覆盖到期可能恢复原始范围，清单中的快照行须与有效权限一同核对。
4. 目标环境逐项完成核对之后再彻底下线兼容鉴权。新学年已禁止建立阶段映射，已有学年的映射只读。
