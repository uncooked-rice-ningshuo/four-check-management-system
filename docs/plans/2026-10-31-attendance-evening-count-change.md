# 到课率与晚自习计数口径调整计划

目标：到课率以节次描述缺课；晚自习每次违规基础计 1 次，再按适用倍数计算，不再以固定学时计算。到课率按缺课节次数乘倍数计违纪次数。现有数据属于测试阶段，不要求旧口径兼容；已定稿快照仍按项目约束保护。

1. 核对到课率录入、列表、提交、导入模板、通报及修正页面的单位，按已确认口径添加回归测试并统一描述；不能将历史快照字段值直接改写。
2. 为晚自习手工录入与 Excel 确认增加服务端回归，证明有权录入时按单次违规乘周倍数计数、倍数未配置时明确失败，拒绝客户端伪造服务端派生字段，并覆盖越权和失败路径。
3. 追加迁移以兼容既有晚自习明细，保留历史数据与快照；同步领域模型、写入、读取、提交快照、导入适配、模板、通报统计和契约。旧 API/运行版本兼容方案必须通过测试，不能只隐藏界面中的学时。
4. 更新晚自习页面、抽屉、提交明细和通报，去除固定学时提示，展示基础次数、倍数和计入次数；检查历史数据及失败状态。
5. 在一次性 PostgreSQL 验证迁移、手工与导入链路，运行后端格式、vet、完整测试；运行前端聚焦、lint、完整测试、构建及匹配的真实浏览器回归。更新当前项目状态，分别记录模型、API、页面、模板、真实环境及角色验收。
