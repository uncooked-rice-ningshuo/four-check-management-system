- **范围**：周通报汇总的授权撤销路径——管理员移除权限后，服务端拒绝、HTTP 客户端处理和页面缓存展示是否保持一致。

## 发现

### [P2] 汇总权限被撤销后，页面仍展示旧缓存

**预期行为**：仓库规则要求权限变更使相关会话失效，并要求受保护 API 在服务端检查当前动作权限与数据范围（`AGENTS.md:190,192`）。管理员可以删除用户权限规则（`server/internal/httpapi/router.go:197-200`）；汇总服务每次读取都会重新计算当前 `REPORT_VIEW` 权限，缺少有效授权时返回 `ErrForbidden`（`server/internal/reporting/service.go:82-100`）。HTTP 层会将该错误映射为 `403/FORBIDDEN_SCOPE`（`server/internal/httpapi/reporting_handlers.go:55-60`）。

**可达场景**：通报查看者先打开汇总页并成功读取数据；管理员随后删除或收窄其 `REPORT_VIEW` 规则；查看者点击“刷新汇总”。后端现在拒绝请求，但客户端只在 `401` 时续期或清会话；`403` 作为普通 `ApiError` 抛出（`web/src/shared/api/httpClient.ts:72-75,108-130`）。

**缺陷与影响**：页面在任何刷新错误时都保留 `summary.data`，并只要该数据存在就继续渲染部门/校级汇总表（`web/src/pages/report/WeeklyReportSummaryPage.tsx:107-129`）。现有组件测试明确验证刷新失败后旧值 `42` 仍显示（`web/src/pages/report/WeeklyReportSummaryPage.test.tsx:50-77`）。因此，发生 `403/FORBIDDEN_SCOPE` 后，已失去通报权限的账号仍可从当前页面看到上一次成功读取的汇总数据；拒绝状态与屏幕上展示的数据不一致。

**反驳检查**：服务端确实拒绝撤权后的新汇总请求，SQL 也在聚合前执行当前范围过滤；但这不能清除已缓存的 `summary.data`。认证会话失效监听器会清除 Query 缓存（`web/src/app/providers/AuthProvider.tsx:40-46`），而 `403` 不会触发该监听器，所以这里没有覆盖权限撤销的保护机制。

**建议修正**：对 `403/FORBIDDEN_SCOPE` 清除通报汇总缓存并取消当前周期选择，显示无权访问状态；只在网络故障或服务端临时错误时保留最近一次成功数据。增加组件或真实浏览器回归：先显示一份汇总，再让刷新请求返回 `403`，断言表格和旧计数不再可见。

## 修复与验证（2026-10-25）

- **实现**：周汇总查询收到 `403/FORBIDDEN_SCOPE` 时调用页面拒绝处理器，立即清除当前周期缓存、清空选择和旧周期选项并重新读取可见周期；用户收到权限变化提示。普通 503/网络错误仍保留最近一次成功汇总。活动查询被移除后不会继续自动重试，因此旧值不会在重试间隔内保留展示。
- **组件回归**：新增测试覆盖“先成功读取，再刷新遇到 403”，断言旧记录计数和汇总表消失、缓存移除、403 请求未自动重试。该用例在修复前失败，修改后通过；同文件 2 项均通过。
- **浏览器回归**：使用一次性 PostgreSQL/MinIO、真实 API/Vite 与 Chrome `156.0.8078.48` 注入 403，确认表格及部门行不可见、拒绝请求只发一次，并在重新选择可见周期后恢复。最终浏览器报告为 22 场景通过，浏览器错误、意外控制台错误和清理错误均为 0：[完整回归报告](../output/playwright/8558b300b0/summary.json)。默认沙箱阻止临时服务启动后，按隔离测试流程在许可执行环境完成了回归。
- **全量前端检查**：Node `v22.23.0`、pnpm `11.7.0` 与仓库声明/锁文件一致；`pnpm lint`、`pnpm test`（76 文件 / 407 项）和 `pnpm build`（含 `tsc -b`）通过。测试输出有既有 CSS 解析提示；build 主 JS `2,225.05 kB` 并保留既有大 chunk 提示。
- **状态与边界**：该缓存显示问题关闭。后端权限检查仍是权威边界；本修复不代表通报定稿/下载路径已存在，也没有覆盖 A01 之外的安全审计类别。

## 已检查的保护

- 汇总服务不信任前端按钮状态，每次请求重新读取有效权限。
- 权限与周次、检查类型和部门范围条件在数据库聚合前编译进 SQL；查询值使用参数传递。
- 后端对无权用户返回稳定拒绝码；前端的登录身份切换/会话失效会清理私有 Query 缓存。
