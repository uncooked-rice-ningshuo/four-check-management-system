# 导入源文件补偿（2026-10-04）

实际 PostgreSQL/MinIO 复现：上传完成后的文件是 AVAILABLE，Discard 却调用只允许 PENDING 的 MarkFileFailed；建批次失败后回收因此始终失败。新增专用 MarkImportSourceDiscarded，在同一事务内锁定文件、核对本人/IMPORT_SOURCE/AVAILABLE/未关联批次，再标记 FAILED 并写审计。通用上传失败状态转换保持 PENDING 限制。

CreateImportBatch 在事务内锁定同一文件并重新核对状态、用途和归属，避免文件回收与批次关联同时成功。服务先持久化待恢复状态再删除对象；审计失败不删除对象。HTTP 补偿使用脱离原请求取消、独立5秒截止时间的context，失败安全记录文件ID及错误类型，保留原建批次错误响应，不记录对象key或底层错误文本。
