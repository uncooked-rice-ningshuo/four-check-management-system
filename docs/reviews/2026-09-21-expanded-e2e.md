# 2026-09-21 已实现功能的 Playwright 补验

## 范围和结论

本轮补跑此前未覆盖的到课率模板交付、导入、草稿维护及基础平台代表性流程，并重跑登录和校历回归。使用当前工作区源码、一次性 PostgreSQL、独立 MinIO、真实 API/Vite 和 Google Chrome；未向业务库写入测试数据，未替换业务 API 或发布业务模板。

这不是二阶段总验收：其余六类页面、部门流程、六类导入和安全回滚尚未交付，无对应页面可测。管理页面的加载覆盖与代表性写操作，也不等于全部角色/范围/字段组合通过。

最终运行编号与统计见下方“验证证据”。历史失败记录保留，用于区分产品缺陷、测试定位错误与后续修复。

## 发现并修复

1. **导入后缓存刷新遗漏。** 原实现只失效与导入目标完全相同的查询，漏掉部门留空的列表及工作台。新增 Hook 行为测试真实 RED（数量仍为 0），修复为失效到课率查询和工作台查询；浏览器补连续第二次导入、直接确认后列表刷新。
2. **完成批次残留。** 浏览器运行 `4e1fbb815e` 复现完成后重载自动打开旧批次抽屉，阻挡下一次操作；新增组件测试先失败，再在关闭已完成批次时清理路由批次引用，未确认批次仍保留恢复能力。
3. **基础数据弹窗清空快速输入。** 运行 `b3db07a168` 复现“新增院系”输入名称后保存显示必填错误。根因为打开时初始化后，`afterOpenChange` 又执行一次 reset。去掉动画结束时的重复初始化，仍在挂载后立即初始化；浏览器在输入之后等待动画完成并校验值，避免通过延迟输入掩盖缺陷。

早期脚本还出现 CLI 沙箱没有全局 URL、Ant Design 虚拟 option 不可点击、中文按钮内部空格和夹具重复记录等问题；依据快照修正定位器/夹具，它们不计为产品修复，也不把这些失败运行记为通过。
