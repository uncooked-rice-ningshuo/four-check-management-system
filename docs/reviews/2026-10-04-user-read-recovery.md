# 用户页读取失败与重试

原页面将用户查询失败当成空数组，显示“暂无用户/共0名用户”；组织目录失败时，已有归属ID未匹配名称又被显示为“已停用”。新增三项组件回归先失败，确认错误态缺失。

用户列表与组织目录现在分别显示失败提示和原位重试。首次用户查询失败不显示正常空态和零计数；有缓存时明确标为上次结果。归属名称不可用不再宣称停用。表格刷新同时重取用户与目录。

目录尚未加载时不开放编辑；已打开的编辑表单遇到目录刷新失败保留输入，展示重试，禁用归属选择和保存，并在提交路径再次拦截，避免回车绕过。恢复目录后原表单继续可用。新增账号本身不依赖归属目录，保持可用。
