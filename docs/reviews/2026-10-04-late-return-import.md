# 晚归导入增量（2026-10-04）

## 范围与决定

- **模型/迁移**：复用检查主表、晚归扩展表和 014 回滚迁移；无新迁移。每名学生每次晚归一条，精确时间作为事件身份，单次违纪数由服务器固定为 1，宿舍不参与去重键。
- **模板/配置**：`LATE_RETURN_IMPORT` v1，工作表“晚归导入”；七列为学号、姓名、班级、晚归日期、晚归时间、宿舍完整名称、备注。宿舍按“宿舍区 楼栋 房间号”填写，必须匹配学生当前有效住宿。CLI 显式 `--type-code LATE_RETURN`，仅在一次性环境发布。
- **API**：通用 `/imports/inspections` 模板下载与上传，原到课率和课程入口拒绝晚归模板。批量加载学生及宿舍时下推班级/年级范围；预览与确认均校验住宿，确认锁定学生/班级/年级、房间、楼栋及宿舍区。关系变化 409，不静默替换引用。共用事务、版本、幂等和审计。
- **页面**：独立导入目标、模板、时间及宿舍预览、关闭恢复批次、确认、列表批次入口、整批回滚及失败重试。确认与回滚使晚归列表及工作台缓存失效。
- **角色验收**：本次新增 HTTP 类型边界及匿名 401；真实浏览器使用隔离管理员。完整普通成员、部门管理员、查看和拒绝组合仍待总门禁。
- **真实环境**：代码与一次性 PostgreSQL/MinIO/API/Vite 已验，业务环境未加载或发布模板。未提交、推送、部署或写业务库。
