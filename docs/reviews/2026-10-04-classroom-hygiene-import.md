# 教室卫生导入增量验收（2026-10-04）

## 范围与决定

沿用D3对象检查口径：一行对应教室的一个区域、一次检查；优秀/合格/不合格互斥，不合格必须填写当前类型原因。责任班级必填，责任学生可空；多人、多班级以分号分隔。不输入累计次数。

模板 `CLASSROOM_HYGIENE_IMPORT` v1 / 工作表“教室卫生导入”，字段顺序为：教室完整名称、检查区域名称、检查日期、检查时间、检查轮次、检查结果、责任班级、责任学生学号、原因名称、情况说明、备注。时间与轮次二选一。教室使用教学楼名称加教室号，区域名称必须在该教室内唯一匹配；同名区域属于其他教室时不能替代当前对象，完整名称歧义拒绝预览。

复用共有卫生责任、领域校验和导入事务；仓储仅加载本批次请求的启用对象、区域与原因，区域记录保留所属教室。确认前再次锁定并核验区域、教室、原因和责任归属，变化整批失败。确认后保留原预览名称快照。
