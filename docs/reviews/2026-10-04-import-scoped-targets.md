# 导入班级、年级目标选择（2026-10-04）

## 问题与范围

班级限定和年级限定账号有导入权限，但原共用抽屉只能选择部门，模板请求缺少限定维度，服务端正确返回403。到课率旧入口还直接继承列表班级/年级，混淆查看范围与导入归属。恢复批次重新上传时原实现只保留部门。

修复保持服务端权限语义不变：共用抽屉独立选择班级、年级；新导入清空列表传入的这两项；已有批次使用持久化范围，重新上传保留原范围。部门变化清空班级/年级，年级变化清空班级，范围变化清空已选文件。选项失败禁用上传并可重试。

上下文选项API增加 `kind=grades` 和 `grade` 筛选，继续在SQL内使用有效权限过滤。批次传输契约声明可选 `classId` / `grade`；通用上传校验返回范围与请求一致，批次读取校验结构，不接受错误类型。
