# 周通报 Word/Excel 输出字段与版式规格（v1）

> **2026-11-10 输出交互修订：** 用户从工作台或归档选择报告版本后，Word/Excel 即时生成、校验并直接下载；不再保存新生成的文件对象或显示“已生成文件”列表。结构化报告版本、统计快照和导出审计仍保留。旧文件记录不在本次变更中批量清理。下文涉及保存文件产物的旧表述以此修订为准。

> 日期：2026-11-07
> 状态：v1 字段与版式基线于 2026-11-07 冻结；本节保留当时设计背景。当前本地 Word/Excel 生成与指标快照实现、验证和目标环境状态以[项目当前状态](../project-status.md)为准。
> 适用：周通报工作台与归档中，基于用户明确选择的某一报告数据版本生成 Word/Excel 可查看文件。

## 1. 规格依据与解释

用户明确：所给第八周 Word/Excel 是**版式参考**，不是完整字段清单；文件中没有的内容可以根据当前系统字段和业务规则另行纳入。文件生成只负责把用户选中的草稿或定稿数据版本转换成可查看文件，不执行数据修正、审核、定稿、发布或回写。

因此字段依据分为两层：

1. **数据事实以当前报告版本快照为准。** 生成器读取选定版本内的类型、汇总行、记录及已保存的更正/纳入调整；不得回查可变的当前记录去补历史值。
2. **统计指标按报告数据版本保存。** 此前确认的首批文件范围是已确认记录数和明细；用户最新决定将指标规则纳入周报草稿/定稿数据。该范围变更由[周通报指标性数据计算与展示实施方案](2026-11-07-weekly-report-indicator-statistics-plan.md)定义：先在草稿数据版本计算并保存，再由 Word/Excel 读取快照呈现。文件生成器不计算指标。

本稿核对了以下材料和实现：

- 第八周 Excel：`参考文件/学生会办公室材料参考/2025-2026下Excel/定/第八周日常管理通报  （定  稿)  .xlsx`
- 第八周 Word：`参考文件/学生会办公室材料参考/2025-2026下word/定/第八周日常管理通报   （定  稿） .docx`
- 指标规则：`参考文件/学生日常检查指标统计规则说明文档.md`
- 当前统计与周通报需求：`docs/plans/2026-10-25-statistics-and-weekly-report-requirements.md`，以 2026-11-01 更新为当前基线
- 当前报告字段：`server/internal/reporting/model.go`、`server/internal/reporting/service.go`、`web/src/entities/reporting/model/reporting.ts`、`web/src/features/reporting/ui/ReportRecordTable.tsx`

## 2. 样例实际结构

### Excel

样例有 6 张工作表：到课率检查情况、晚归检查情况、卫生检查情况、早锻炼情况、无机课堂、教室卫生。每张表为独立类型明细，没有汇总页和公式。样例包含姓名、班级、学号、日期、事件次数/学时、原因、备注，以及宿舍或教室等对象字段。工作簿没有冻结窗格、打印区域、重复表头或页面缩放设置，并有一条未核实的外部链接。

### Word

样例包含学院/周次标题、正文说明及 17 张表，实际 11 个分节。表格除个人/班级事件明细外，也包含到课率、早签率、应到/实到人数、班主任和处分规范等内容；公共区卫生、私拉电线表只有表头。样例未覆盖当前八类中的晚自习，也没有与当前公共宿舍卫生数据模型一致的责任宿舍字段表。

使用本机随附的 LibreOffice 渲染器检查后，样例转成 21 页；中文字体未能正常显示，且出现大段留白和表格续页。该结果只能用于识别分节、横纵向和表格式样，不能作为生成模板版式通过的证据。生成模板需要采用可用的中文字体与稳定分页，并在目标 Office/WPS 环境验收。

## 3. 当前代码可直接支持的共同字段

报告版本摘要（`ReportVersionContent`）当前含：学年/学期/周次及日期范围、范围是否受限、统计规则版本、确认记录总数、按部门/校级范围 × 检查类型的记录数与确认零记录回执数、数据状态、未完成单元、更正/纳入调整摘要、生成时间及可选 `indicators` 快照。指标快照包括生成时冻结的班级人数、早签计划日期、周倍数、班级/全周指标和结果。每条记录快照含类型、姓名/学号/班级/年级、检查来源、类型化明细、相关课程/教室/宿舍/区域/原因显示名称及责任班级/学生/宿舍标签。

输出文件的内部产物元数据还需关联：不可变报告版本 ID/版本号、所选数据阶段（草稿或定稿）、格式、模板版本、生成者、生成时间、文件大小与 SHA-256。报告版本状态与文件生成状态分开保存。

记录 ID、来源提交 ID、数据库 `rowVersion`、对象存储 key、权限明细和审计内部字段不是面向文件读者的业务列，不输出。内部文件可显示所选版本快照中的学号；来源单位按 `ReportVersionContent.rows` 中冻结的名称显示，不读取记录查询返回的当前单位名称。服务端必须对生成/下载执行导出权限检查。

## 4. 按检查类型的字段映射

下表的记录明细列只使用选定报告版本保存的明细；指标摘要另按该版本已保存的指标快照输出。未知数值和来源字段留空或显示“—”，不从其他记录、当前主数据或统计公式补造；Word 中已确认没有对应人员或课程的文本列显示“无”。记录级 `penaltyMultiplier`、`penaltyHours`、`penaltyCount` 字段存在时按版本快照原样展示；周指标中的折算次数读取指标快照里的倍数与最终值，文件生成不再计算或跨周累计。

| 检查类型 | 首期文件明细字段（建议顺序） | 需要避免照搬/补算的样例或指标 |
| --- | --- | --- |
| 到课率 | 姓名、班级、学号、年级、缺课日期/时间、课程、教室、节次、缺课学时、已保存的单条适用倍数/计入学时、备注 | 到课率分子/分母及 distinct 违纪人数从数据版本指标快照读取；实际人数和比率不乘处分倍数。不从样例推造班主任。 |
| 无机课堂 | 姓名、班级、学号、年级、违规日期、课程、课程节次、教室、已保存的单条计入次数/倍数、备注 | 新代码已补齐节次采集，并按学号身份＋规范化节次在周内判重；迁移 041 和导入模板 v3 尚未应用/发布。不从样例的空表或旧累计学时字段推断记录；不输出班级到课率。 |
| 早锻炼/早签 | 姓名、班级、学号、年级、缺勤日期、缺勤次数、备注 | 应到人数和天数取该报告版本快照；实际缺勤人次用于出勤人次/率，处分计入次数另按周倍数折算；两类值都由数据版本保存。 |
| 晚自习 | 姓名、班级、学号、年级、缺勤日期/时间、教室、节次、已保存的单条计入次数/倍数、备注 | 只列确认的缺勤记录；不推导应到人数、到场率或缺勤率。样例没有此类附件。 |
| 宿舍卫生 | 宿舍、责任班级、责任学生、检查日期/时间、轮次、检查结果、原因、情况说明、备注 | 只输出不合格次数和宿舍卫生/公共宿舍卫生两分支及其合计；不输出缺检次数。责任人按版本内责任对象标签输出。 |
| 晚归 | 姓名、班级、学号、年级、晚归日期/时间、宿舍、备注 | 不输出共查寝间数或晚归率；明细只读已纳入版本的唯一有效记录，周计入次数读取已冻结的倍数结果。 |
| 教室卫生 | 教室、责任班级、责任学生、检查日期/时间、轮次、检查结果、原因、情况说明、备注 | 只统计不合格检查记录，不输出应检/已检/缺检次数；不从当前班级主数据补写班主任。 |
| 公共宿舍卫生 | 责任宿舍、责任班级、责任学生、检查日期/时间、轮次、检查结果、原因、情况说明、备注 | 只输出该分支不合格次数；当前类型表示责任宿舍，不记录公共区域对象，不能照搬样例的公共区域/私拉电线字段。 |

类型排序遵循用户选定顺序，不在生成器中把部门与检查类型关系写死。Word 按历史通报的班级/明细版式输出，Excel 按记录明细字段输出，两者只读取同一冻结报告版本，不强求列结构相同。

## 5. 指标快照包含的字段

用户已决定将规则文档中的本周指标纳入周报数据版本。源码现已在完整范围版本保存以下指标及输入快照；文件生成需原样读取，不得临时计算。受限范围不生成全周指标，历史无快照版本不以当前输入补算。学期累计留到项目阶段四；综合排名不属于本轮范围：

| 规则说明中的指标/规则 | 需要保存或冻结的数据 | 当前实现状态 |
| --- | --- | --- |
| 到课率、实到人数、应到人数 | 生成时班级人数、版本中缺课学号、班级/全周人数与比率 | 已实现；人数不乘倍数，率保留两位小数。 |
| 无机课堂违规次数/人次/人数 | 底层唯一事件、班级/全周人数、周倍数和折算结果 | 已实现；违规人次与折算次数一致， distinct 学生数不乘倍数；迁移/模板环境准备待完成。 |
| 早签出勤率/人次 | 生成时班级人数、计划日期、版本记录、实际出勤人次/率、周倍数和折算次数 | 已实现；出勤率按真实人次计算，折算次数单独展示。 |
| 晚自习缺勤次数/人次 | 唯一有效记录、周倍数与折算结果 | 已实现；次数与人次分别展示并取相同折算值。 |
| 教室卫生不合格次数 | 不合格记录、周倍数与折算结果 | 已实现；不统计应检、已检或缺检。 |
| 个人宿舍卫生与宿舍公共卫生不合格次数 | 被检查对象、日期、分支、不合格结果、周倍数与分支合计 | 已实现；底层按被检查对象＋日期判重，分支及合计分别保存；不统计缺检。 |
| 晚归次数/人次 | 唯一有效记录、周倍数与折算结果 | 已实现；次数与人次分别展示并取相同折算值。 |
| 周末统计周归属 | 业务日期、实际统计周及相应校历规则 | 沿用来源记录已有的统计周归属；报告不重写周归属。 |

## 6. Word/Excel 建议版式与空数据处理

### Word

2026-11-10 本地版式补充：附件主标题采用“第八周到课率检查通报”等汉字周次格式；通报首页支持汉字周次变量及阿拉伯/汉字页码模板，页码与总页数使用 Word 动态域。表头和数据单元格垂直居中，数据行最小高度 600 twip；按估算高度分页，达到 3500 twip 的单行独占一页，续页重复表头。若单行内容超过纸张可用高度，Word 仍可能将其跨页，不能为满足分页而截断学生数据。是否把样例中合并的卫生附件改成系统的跨类型组合，需另行确认。

- 首页/正文开头只放学院名称、通报标题、学年/学期/周次、对应数据阶段与版本号、数据范围是否受限、版本生成时间。标识“本文件按该数据版本生成，仅供查看；数据状态以系统为准”。文件生成时间单独标示。
- 随后放所选数据版本已保存的指标摘要与现有报告数据状态，再按类型分节列指标及明细；宽表允许横向页面，但每张表有重复表头，分页不拆开单条记录。不新增指标层“待定/部分计算”状态。
- 不自动附加历史法规、处分阈值、三日说明要求、签发人或落款日期。它们不是报告数据字段，须另有经确认的通报固定文案后才能加入。

### Excel

- 每个所选版本实际包含的检查类型各一张明细表，顺序按检查类型配置；不因有八类历史样例而把版本未包含或无权查看的类型加入文件。
- 每张表首部显示类型名称、学年/学期/周次、对应数据阶段与版本号、数据状态和记录数；随后为稳定字段表头和逐条记录。冻结标题/表头、启用筛选、设置重复打印行/打印区域；学号按文本保存，所有用户文本以纯文本写入，不能变成公式。
- 指标汇总只能读取所选数据版本中已保存的指标值；不使用工作簿公式临时计算或引用其他周的数据。具体汇总页/分类型指标列在指标快照冻结后补入模板规格；源样例的外部链接不复制。

### 空值、零回执和未完成状态

- 已确认零记录回执：显示“已确认零条记录”及回执数；不添加虚构明细行。
- 无已确认数据：显示“暂无已确认数据/未收到确认数据”，不得显示成确认零条或“无异常”。
- 强制生成但存在未完成单元：在摘要显式标为“部分数据未确认/未完成”，已确认明细仍独立列出；不能用空白表替代未完成提示。
- 受限范围：在标题/摘要标明“仅当前授权范围”，不得呈现为全院完整结果。

## 7. v1 输出决定

1. **指标范围：** 指标纳入报告数据版本；在指标快照实现前，不得通过文件生成器临时补算。次数型违纪指标按周倍数折算，实际人数和出勤率不折算；Word/Excel 文件模板只读快照值。
2. **单条计入字段：** 版本快照已有的事件级倍数/计入值作为明细原样输出，按类型字段单位显示；不在生成时二次计算或跨周累计。
3. **个人与来源字段：** 仅在受限的内部下载文件中输出记录快照已有的学号和来源单位；外发场景另行脱敏并确认下载权限。
4. **固定正文/落款：** 生成数据标题、数据状态摘要、本周指标快照与分类型明细，不复制样例中的法规引文、处分规范、三日说明要求、签发人或历史日期。
5. **兼容性与版本：** 初版模板记为 `T1`；修改字段、字段语义或版式时递增版本。只用标准 `.docx` / `.xlsx`，不复制外部链接、宏或依赖公式；Office/WPS 目标版本在阶段五用黄金样例验收。

## 8. 黄金样例验收集

实现阶段用虚构数据构造，不复制样例中的真实学生信息。黄金集至少覆盖：八类各一条已确认记录；多部门同类型记录；确认零记录回执；无已确认数据与未完成单元的区别；范围受限版本；一个被更正字段与一条排除/恢复纳入调整；中文长文本、空可选值、超长分页和以 `= + - @` 开头的文本。

每个黄金样例需逐字段比对：Word/Excel 都只反映选择的同一报告版本，记录数、本周指标分子/分母、原始次数、周倍数、折算次数、比率、字段值和类型顺序相符；文件生成不二次去重或计算。不新增缺检、待定指标状态。学期累计和综合排名不在本轮输出范围内。文档打开与分页在目标 Office/WPS 复核；生成失败、重试、下载都不改变报告数据状态、版本号、修订轨迹或来源锁。
