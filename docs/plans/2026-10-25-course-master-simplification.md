# 课程主数据轻量化实施记录

## 已确认决定

课程主数据在当前业务中只用于标识一条到课率、无机课堂或其他关联记录属于哪门课，因此课程维护表单只保留课程名。课程名全局唯一；启用状态继续作为基础数据的可用性管理字段。

课程选择统一使用服务端模糊搜索下拉框：输入最多 128 个 Unicode 字符，每页 20 条，列表高度不超过 320px，滚动到底继续加载；API 将课程页大小限制为 50。搜索不按班级、日期、学期排课、教室或节次过滤。

课程与记录的发生事实分开保存：学生及其班级、检查日期和时间、实际上课教室、节次与旷课学时仍属于记录。系统继续校验学生与班级、引用对象启用状态、日期属于所选周次、到课率学时与所选节次一致、重复记录及数据权限；不再要求课程与这些事实有预设关联。

## 实施边界

- 管理界面、领域 API 与后台写入只维护课程名和可用状态，不再读取或写入教师、授课班级和排课关系。
- 到课率、无机课堂手工表单使用同一课程选择器；手工到课率请求提交课程 ID。其他课程表单复用相同的分页搜索端点。
- 课程候选列表面向已授权的检查范围；选项数据不依赖当前记录的班级、日期、教室或节次。
- 为保留历史数据，本次不删除 `teacher_id`、`course_classes`、`course_schedules` 等旧列和旧表，也不再将它们用于页面、记录校验、导入确认或课程筛选。若将来需要物理清理，须另行规划数据保留与迁移。
- 不改变检查记录已保存的课程 ID、名称快照、班级、教室、时间与节次，不改重复键、统计口径、权限或部门流程。

## 完成范围

- 课程基础数据页面简化为课程名维护。
- 建立服务端模糊查询及分页选项接口，并在相关手工表单接入滚动加载课程选择器。
- 移除手工创建、记录编辑、Excel 预览和确认路径中的课程排课/班级/日期/教室/节次匹配校验。
- 更新对应单元测试、接口测试和项目状态；完整验证结果在项目状态记录。
