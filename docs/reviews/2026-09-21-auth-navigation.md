# 2026-09-21 认证刷新整页跳转诊断

## 结论与边界

2026-10-04 更新：数据库保存失败已另行实现[原子轮换与失败恢复](2026-10-04-refresh-atomic-rotation.md)，保留严格单次消费。下文“先消费再保存”是本诊断时的历史实现；成功提交后响应丢失仍未修复，本诊断结论和边界继续有效。

现象已复现，未修复。当前刷新令牌为严格单次消费：服务端先消费旧令牌，再签发并保存新令牌，最后经 Set-Cookie 交给浏览器。整页跳转可打断响应交付；浏览器仍持有旧令牌，下一次刷新得到 401 INVALID_SESSION 并返回登录页。单页导航避开初始化刷新，不能作为此问题已修复的证据。

受控实验确认“成功轮换但响应未交付”足以造成问题；自然跳转实验只记录浏览器状态码，未逐请求捕获服务端事务，因此不能断言每一次自然失败均发生于相同事务时点。数据库最终汇总存在未撤销会话，与丢失新令牌一致，但不是逐次因果证据。

不采用允许旧令牌重放的临时放宽。透明恢复需要进一步设计重试识别、并发轮换和旧令牌拒绝规则；不能凭诊断擅自改变安全语义。本次没有修改认证运行时代码。
