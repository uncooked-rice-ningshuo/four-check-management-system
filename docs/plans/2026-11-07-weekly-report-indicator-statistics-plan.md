## 1. 本周要统计哪些指标

| 检查类型 | 班级维度 | 全周维度 |
| --- | --- | --- |
| 到课率 | 违纪人数、实到人数、应到人数、到课率 | 全周去重违纪人数、总实到人数、总应到人数、到课率 |
| 无机课堂 | 违规次数、违规人次、违规人数 | 各班违规次数/人次之和、全周去重违规人数 |
| 早锻炼/早签 | 应到人次、实际缺勤人次、出勤人次、出勤率；另保存倍数折算的违纪计入次数 | 总应到人次、实际缺勤人次、出勤人次、出勤率；另保存折算违纪计入次数 |
| 晚自习 | 缺勤次数、缺勤人次 | 各班缺勤次数/人次之和 |
| 教室卫生 | 责任教室不合格次数 | 各班不合格次数之和 |
| 个人宿舍卫生 | 分支不合格次数 | 各班/个人分支不合格次数之和 |
| 宿舍公共卫生 | 分支不合格次数 | 各班/个人分支不合格次数之和 |
| 宿舍卫生合计 | 个人宿舍卫生 + 宿舍公共卫生不合格次数 | 各班合计之和；两分支明细仍分别保留 |
| 晚归 | 晚归次数、晚归人次 | 各班晚归次数/人次之和 |

本轮不统计缺检次数、学期累计次数/学时、处分阶梯或综合排名。宿舍两分支的周不合格次数分别留存，合计数作为规则指定的宿舍卫生处分口径；本轮不扩展学期累计。各“次数/人次”按本周教学倍数折算；人数及实际出勤率仍反映实际发生的学生/缺勤情况，不乘倍数。

## 2. 指标需要的数据及数据要求

### 共用要求

1. 以报告周为统计范围，先按业务归属周筛选记录。原规则中的“周末违纪归入下一周”仍适用于周归属。
2. 事件类次数以底层已通过唯一业务键校验的有效记录为基础，不在周报统计服务重复清理相同记录；用户公式明确要求的 distinct 学生人数仍按学号汇总。
3. 只统计所选报告数据版本实际纳入的记录；未提交的数据按现有周报流程处理，不新增指标层状态或补造记录。
4. 应到人数、早签计划天数及倍数配置在草稿生成时读取并随报告数据版本保存，不能用当前可变配置回算已生成的版本。

### 各指标的数据清单

| 指标 | 必需数据 | 关键要求 |
| --- | --- | --- |
| 到课率 | 统计周、班级、应到人数、缺课记录（学号） | 到课率人数按公式对学号作 distinct 汇总；这是“人数”计算，保留在统计层。应到人数须冻结到周报版本。 |
| 无机课堂 | 统计周、班级、学号、课程节次/业务事件标识 | 事件次数从底层唯一有效记录计数；全周次数/人次按班级结果求和，违规人数按学号全周 distinct。当前数据库键与“学号+课程节次”存在差异，见第 4 节。 |
| 早锻炼/早签 | 班级应到人数、周配置早签计划天数、缺勤记录（学号、日期） | 早签天数直接取该周配置的计划天数，默认 5 天；缺勤事件由底层唯一记录约束。人数与计划天数在草稿生成时冻结。 |
| 晚自习 | 统计周、班级、学号、日期 | 事件次数直接计底层唯一有效记录；全周次数/人次按班级结果求和。 |
| 教室卫生 | 班级责任教室、不合格检查记录、检查日期 | 只统计不合格记录，不采集或计算应检、已检、缺检次数。复查规则仍按原规则，不把同一次检查的整改复查重复计为另一条不合格。 |
| 个人宿舍卫生 | 班级/责任学生、被检查寝室、检查日期、分支、不合格结果 | 只统计不合格分支；底层按被检查对象+日期判重；不采集或计算缺检次数。 |

| 晚归 | 统计周、班级、学号、自然日 | 事件次数直接计底层唯一有效记录；全周次数/人次按班级结果求和。 |

## 3. 每项指标怎么算

令 `M` 为该周配置的教学周倍数：普通周为 1，教学周按规则为 2。事件计数类的计入次数 = 底层已通过业务唯一键校验的原始事件数 × `M`；统计层不再重复清理同一个事件。`COUNT(DISTINCT 学号)` 是人数指标，仍按学号汇总且不乘倍数。到课率和早签出勤率反映实际出勤情况，使用实际缺勤人数/人次计算，不用处分倍数改变实际出勤率。报告版本保存原始事件数、`M` 和折算计入次数，以便复核。

### 3.1 到课率

**班级（单周）**

- `班级违纪人数 = COUNT(DISTINCT 学号)`，范围为本班本周至少有一条缺课记录的学生。
- `班级实到人数 = 班级应到人数 − 班级违纪人数`。
- `班级到课率 = 班级实到人数 ÷ 班级应到人数 × 100%`。

**全周（全部班级）**

- `全周违纪人数 = COUNT(DISTINCT 学号)`，范围为本周全部班级有缺课记录的学生；同一学号全周只计一次。
- `总应到人数 = Σ 各班应到人数`。
- `总实到人数 = 总应到人数 − 全周违纪人数`。
- `全周到课率 = 总实到人数 ÷ 总应到人数 × 100%`。

全周违纪人数按学号全局 distinct 汇总，即使同一学生本周在多个班级/课程有缺课记录也只计一次。它是人数而非事件计入次数，不乘 `M`。规则说明文档明确到课率保留两位小数。

### 3.2 无机课堂

**班级**

- 原始事件数 = 本班本周经底层唯一键校验的无机课堂记录数。
- `违规次数 = 原始事件数 × M`。
- `违规人次 = 违规次数`（一条原始事件按周倍数计入）。
- `违规人数 = COUNT(DISTINCT 学号)`，范围为本班本周。

**全周**

- `违规次数 = Σ 各班违规次数`。
- `违规人次 = Σ 各班违规人次`。
- `违规人数 = COUNT(DISTINCT 学号)`，范围为全周所有班级，不乘 `M`。

无机课堂与到课率缺课记录分开统计，不互相合并。代码已将无机课堂底层唯一键对齐为同一学期、周和检查类型下的“学生身份（对应学号）＋规范化课程节次”；日期、班级和课程不拆分身份。报告统计直接计版本中的有效记录，不再二次去重。迁移 041 已应用于本机 `four_check`，应用前冲突数为 0、待变更记录数为 0；无机课堂导入模板 v3 已发布、v2 已退役。目标云端或其他环境仍须各自执行迁移与发布流程。

### 3.3 早锻炼/早签

令 `D` 为本周配置的早签计划日期数；默认计划为 5 天，节假日/调课按周配置调整后的日期数计算，并以该配置作为本周实际早签天数。

**班级**

- `班级应到人次 = 班级应到人数 × D`。
- `班级实际缺勤人次 = 本班底层唯一有效的缺勤记录数`。
- `班级出勤人次 = 班级应到人次 − 班级实际缺勤人次`。
- `班级出勤率 = 班级出勤人次 ÷ 班级应到人次 × 100%`。
- `班级计入违纪次数 = 班级实际缺勤人次 × M`。

**全周**

- `全周应到人次 = 总应到人数 × D`（`D` 为周配置早签计划日期数，即本周早签实际天数）。
- `全周实际缺勤人次 = Σ 各班实际缺勤人次`。
- `全周出勤人次 = 全周应到人次 − 全周实际缺勤人次`。
- `全周出勤率 = 全周出勤人次 ÷ 全周应到人次 × 100%`。
- `全周计入违纪次数 = 全周实际缺勤人次 × M`。

周早签天数 `D` 直接取早签周配置中日期的数量（默认 5 天）；该配置在草稿生成时随版本冻结。出勤人次和出勤率使用实际缺勤人次，不使用教学周折算次数。早签率也保留两位小数；分母为 0 时显示“不可计算”。

### 3.4 晚自习

**班级**

- `班级缺勤次数 = 本班本周底层唯一有效记录数 × M`。
- `班级缺勤人次 = 班级缺勤次数`。

**全周**

- `全周缺勤次数 = Σ 各班缺勤次数`。
- `全周缺勤人次 = Σ 各班缺勤人次`。

### 3.5 教室卫生

**班级**

- `班级不合格次数 = 本班责任教室当周“不合格”底层唯一有效检查记录数 × M`。

**全周**

- `全周不合格次数 = Σ 各班不合格次数`。

同一次检查的复查按原规则处理：整改合格不清除原不合格；复查仍不合格不重复增加原检查的不合格次数。

### 3.6 宿舍卫生（个人宿舍卫生与宿舍公共卫生）

**班级/个人**

- `分支不合格次数 = 本周该分支按（被检查对象、检查日期）唯一的底层不合格有效记录数 × M`；该唯一键由底层记录约束负责，报告层不再对相同键二次去重。
- `宿舍卫生不合格次数 = 个人宿舍卫生分支不合格次数 + 宿舍公共卫生分支不合格次数`。
- 两个分支的明细分别保留；合计值另列。
- 本轮不统计或展示缺检次数。

**全周**

- `全周不合格次数 = Σ 各班/个人宿舍卫生不合格次数`。

### 3.7 晚归

**班级**

- `班级晚归次数 = 本班本周底层唯一有效记录数 × M`。
- `班级晚归人次 = 班级晚归次数`。

**全周**

- `全周晚归次数 = Σ 各班晚归次数`。
- `全周晚归人次 = Σ 各班晚归人次`。

### 3.8 与其他全局规则的关系

- 周末违纪归入下一周：先确定每条记录的统计周，再按以上公式汇总；次数型违纪指标乘该周 `M`。
- 教学周倍数只折算事件计入次数，不改变到课违纪人数、违规人数或实际出勤率。每个版本冻结当时的 `M` 和相应计算值，后改周配置不重算旧版本。
- 事件记录是否重复已由底层唯一业务键负责；报告不再对相同事件键做第二轮去重。人数指标中的 `COUNT(DISTINCT 学号)` 仍保留，因为它是在统计“有多少人”，不是重复清理。若底层唯一键与用户指定的业务身份不一致，先修正记录身份/唯一约束，使其符合公式。

## 6. 已确认的实现边界

- 班级人数以草稿生成时的班级人数为准；生成前变化被采用，生成后形成快照，旧报告不变。
- 早签天数按该周周配置中的早签计划天数；草稿生成时冻结，生成后配置变化不改旧报告。
- 删除教室卫生和宿舍卫生的缺检次数，不建设应检/已检覆盖数据；保留卫生不合格次数和宿舍两分支合计。

- 不新增指标层面的“待定值”、部分计算状态或定稿门槛；缺少提交按现有周报规则处理。
- 到课率和早签率均保留两位小数；分母为 0 显示“不可计算”。
- 学期累计留到项目阶段四，综合排名不纳入本轮。Word/Excel 仅转换选中的数据版本为文件。
